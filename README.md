# FC_VWFA_Long
Code associated with manuscript "Functional connectivity scaffolds the emergence of the visual word form area"


1. FC_VWFA_Long_Figures.ipynb
Code to generate main manuscript analysis figures.

2. Predict_VWFA_HyperParameter.py
Hyperparameter tuning for predicting VWFA-2 location from functional connectivity.

3. Predict_VWFA_Permute.py
Run prediction model and perform random permutations to evaluate model performance.

4. Predict_VWFA_Permute_Reg.py
Run regression model to predict distributed text-selectivity in VOTC.
Perform random permutations to evaluate model performance.
